**Итоговый проект**\
\
В течение курса вы будете шаг за шагом осваивать современные генеративные модели для визуальных данных: от базовых архитектур до диффузионных и потоковых подходов, управляемой генерации, редактирования, дообучения и ускорения инференса. Итоговый проект позволит вам применить эти знания на практике и пройти полный цикл исследовательской или инженерной работы.\
\
Ваша задача — выбрать одну из предложенных тем, самостоятельно спланировать эксперимент, реализовать выбранный метод, провести сравнение с baseline, проанализировать результаты и защитить своё решение. Проект выполняется индивидуально в течение семестра. Преподаватели не закрепляются за темами — вы можете задавать вопросы в общем чате курса, и любой эксперт поможет.\
\
Каждый проект состоит из двух этапов: на первом вы разбираетесь в методе, готовите данные и воспроизводите baseline; на втором — реализуете основной метод, проводите эксперименты и защищаете результаты. Подробные критерии оценивания и формат сдачи будут размещены в соответствующих разделах ЛМС (рубежный контроль, зачёт с оценкой).\
\
Все проекты рассчитаны на бесплатные вычислительные ресурсы (Google Colab, Kaggle) и используют датасеты учебного масштаба (CIFAR-10, FFHQ 64×64, AFHQv2 и аналоги). Использование GPT для генерации кода не запрещается, но на защите мы проверяем понимание: вы должны уметь объяснить логику работы каждого блока и обосновать принятые решения.\
\

**Проект «Разные методы генерации из диффузионных моделей»**\
В рамках итогового проекта вам предстоит реализовать DDIM, многошаговый DPM-Solver++ второго порядка и Heun по схеме EDM на PyTorch, проверить их по готовым реализациям в Diffusers. Вы сравните стандартные расписания шагов при одинаковом числе вызовов модели и разработаете алгоритм подбора уровней шума. Для этого последовательно изменяйте положение нескольких опорных уровней, сохраняя их порядок, и уменьшайте отличие результата от генерации с большим числом шагов.\
\
Вам предстоит согласовать входы и предсказания модели с сэмплером, подобрать расписание на фиксированном наборе начальных шумов и проверить его на новых. Исследуйте, на каких участках траектории требуется больше шагов и переносится ли найденное расписание между сэмплерами. Для подбора используйте MSE относительно детерминированной генерации с большим числом шагов при том же начальном шуме. Оцените результаты визуально, по FID, числу вызовов модели и времени генерации, время подбора расписания учитывайте отдельно.\
\
Данные и модели: CIFAR-10 32×32 и DDPM (google/ddpm-cifar10-32). Дополнительно: PixArt-α 256×256 и подвыборка изображений с подписями COCO для проверки на текстовой генерации. Для PixArt заранее вычислить текстовые эмбеддинги и выгрузить текстовый энкодер из памяти GPU.\
\
**Проект «Дистилляция диффузионных моделей»**\
В рамках итогового проекта вам предстоит реализовать один из методов дистилляции диффузионных моделей на выбор: Progressive Distillation или Consistency Distillation. Сначала вы обучите ученика без состязательной потери, затем добавите дискриминатор и состязательную потерю, используя Adversarial Diffusion Distillation как пример сочетания дистилляции и состязательного обучения, после чего сравните учителя и оба варианта ученика по FID, времени генерации и визуальному качеству.\
\
Вам предстоит реализовать полный цикл: подготовить данные, инициализировать ученика весами замороженного учителя, провести серию экспериментов с разными весами GAN-loss, исследовать влияние на качество, разнообразие и устойчивость обучения при одинаковом числе шагов ученика, проанализировать результаты и сформулировать выводы. Оба варианта ученика дообучить из одного промежуточного чекпоинта на одинаковое число шагов.\
\
Данные и модели: CIFAR-10 32×32 и предобученная EDM; для Progressive Distillation также можно использовать DDPM (google/ddpm-cifar10-32). Дополнительно: AFHQv2 или FFHQ 64×64 с соответствующими весами EDM (код и веса NVlabs/edm). Выбрать одну пару «датасет — учитель» и небольшой CNN-дискриминатор. Ученика инициализировать весами учителя при совместимой архитектуре, учителя заморозить.\
\
**Проект «Диффузионные методы переноса стиля»**\
В рамках итогового проекта вам предстоит обучить стилевую LoRA и сравнить её с переносом стиля через готовый IP-Adapter. В IP-Adapter подавайте изображение целевого стиля, а в одинаковый для обоих подходов ControlNet – контуры исходной фотографии. Вы исследуете влияние ранга и коэффициента применения LoRA, а также веса изображения-условия IP-Adapter, сравните постоянные коэффициенты с их изменением по шагам генерации.\
\
Вам предстоит реализовать полный цикл: собрать датасет изображений одного стиля, подготовить отдельные тестовые фотографии, провести эксперименты с разными настройками. Оцените сохранение композиции по контурам, содержания — по DINO-признакам, а стиль — по визуальному сравнению с изображениями целевого стиля. Используйте одинаковые исходные фотографии, текстовые запросы и начальные шумы. Дополнительным плюсом будет сравнение нескольких стилей.\
\
Данные и модели: 30–100 изображений одного стиля из WikiArt и 20–30 тестовых фотографий COCO. Базовый вариант: SD 1.5, IP-Adapter для SD 1.5 и ControlNet Canny для SD 1.5, разрешение 512×512. Дополнительно: SDXL с IP-Adapter и ControlNet Canny для SDXL. Обучать только LoRA с batch size 1, mixed precision и gradient checkpointing, ControlNet и IP-Adapter использовать при генерации.\
\
**Проект «Ускорение диффузионных моделей с адаптивным кэшированием»**\
В рамках итогового проекта вам предстоит реализовать сохранение и повторное использование промежуточных признаков между шагами генерации. Вы сравните обновление кэша через фиксированное число шагов и по изменению доступных признаков, используя TeaCache как ориентир. Исследуете влияние выбранных блоков и частоты обновления, предложите разные пороги для начала и конца генерации.\
\
Вам предстоит адаптировать критерий обновления к выбранной архитектуре и вычислять его до пропускаемых блоков, учитывая затраты времени на проверку. Сравните генерацию с кэшем и без него по времени, пиковой памяти GPU и LPIPS при одинаковом начальном шуме, соответствие тексту оцените по CLIPScore. Покажите визуальные изменения и случаи ухудшения качества. Подберите пороги на отдельных текстовых запросах и проверьте их на тестовом наборе.\
\
Данные и модели: 250 подписей COCO, из них 50 для подбора порогов и 200 для оценки. Модель на выбор: PixArt-alpha 256×256, PixArt-sigma 512×512 или SANA 600M 512×512 (flow matching). Использовать готовые веса, batch size 1, заранее вычислить текстовые эмбеддинги и выгрузить текстовый энкодер из памяти GPU. Настройки точности — по документации выбранной модели.\
\
**Проект «Управляемое редактирование 3D-сцен методом диффузионного inpainting»**\
В рамках проекта предлагается реализовать условную диффузионную модель для локального редактирования компоновки объектов в трёхмерных помещениях. Модель получает план комнаты, категории и размеры объектов, а также частично зафиксированную пользователем сцену и генерирует положения и ориентации только для выбранных объектов. Будут исследованы восстановление удалённой мебели, исправление некорректных компоновок и добавление нового объекта с минимальным изменением остальной сцены.\
\
На первом этапе будет подготовлена подвыборка комнат ProcTHOR-10K и реализован baseline на основе условного VAE или независимого предсказания координат. На втором этапе будет реализован DDPM с permutation-equivariant Transformer, маскированием фиксированных объектов и guidance по пересечениям и границам комнаты. Будут сравнены разные доли редактируемых объектов, веса и расписания guidance, а также число шагов генерации.\
\
Результаты будут оцениваться по частоте и величине пересечений, выходу объектов за границы помещения, выполнению пространственных отношений, локальности изменений, разнообразию, времени генерации и визуальному качеству top-down и 3D-визуализаций.\
\
