1. Обновить README: установка, команды S1–S8, зафиксированные версии из `outputs/s1_baseline/metadata.json`.
2. Короткий `docs/results.md`: что уменьшилось, что нет, переносится ли сетка, цена подбора, ограничения.
3. Демо-скрипт `scripts/s9_demo.py`: 4 заранее сохранённых шума, три сэмплера, Karras vs found, NFE 19.
4. Список вопросов защиты (уже в плане) — прогнать вслух по своему коду.
