# S3 — VP-таблица и адаптер

Зависимость: S2 (для проверки, что `x̂₀` из ε совпадает с DDIM).

## Цель

Один модуль, который считает `β, ᾱ, s` и переводит `x ↔ y`, плюс обёртка U-Net со счётчиком NFE.

## Сделать

1. `src/gencv/noise.py`:
   - таблица из конфига модели, не из дефолтов scheduler;
   - `sigma_from_t`, `t_from_sigma` (на таблице — точное попадание);
   - `x_to_y`, `y_to_x`.
2. `src/gencv/denoiser.py`:
   - `D(y, s) = y − s · ε̂`;
   - вызов U-Net только в x-координатах;
   - NFE += 1 на каждый forward;
   - на `s=0` не вызывать модель, а вернуть `y`.
3. Тесты:
   - `y_to_x(x_to_y(x, t), t) ≈ x`;
   - `x̂₀` из адаптера = формула DDIM;
   - NFE растёт на 1 за вызов.

## Не делать

Heun и DPM. Только таблица и denoiser.

## Запуск

```bash
pytest tests/test_noise.py tests/test_denoiser.py -q
```

## Готово когда

Тесты обратимости и `x̂₀` проходят на CPU и на MPS. Адаптер не содержит обучаемых параметров.
