# S7 — Опоры и поиск сетки

Зависимость: S6.

## Цель

Подобрать положение трёх опор для DPM-Solver++ при NFE 19 относительно Karras.

## Сделать

1. `src/gencv/noise_bank.py` — создать непересекающиеся банки по `configs/default.yaml`.
2. `scripts/s7_references.py` — DDIM 1000 NFE на `search+valid+mse_test` (352 шт.). Сначала замерить скорость; если локально > ~1 часа, остановиться и перенести команду в Colab.
3. На 16 `stability` шумах сравнить 250/500/1000, записать MSE между длинами.
4. `src/gencv/search.py` — координатный спуск, `docs/methods.md` §8.
5. Журнал каждого кандидата: сдвиги, timesteps, MSE_search, NFE, секунды.
6. Лучшие несколько — на `valid`, зафиксировать `data/schedules/found.yaml` **до** теста.
7. Три контрольные сетки (только ранняя / средняя / поздняя опора) тем же бюджетом, тоже зафиксировать.

Локально начать с полного поиска. Colab — только если опорные 1000-NFE не влезают.

## Запуск

```bash
python scripts/s7_make_banks.py
python scripts/s7_references.py
python scripts/s7_search.py
```

## Готово когда

Есть `found.yaml`, `search_log.csv`, три контрольные yaml, время подбора отдельной цифрой. Повторный запуск поиска с теми же входами даёт ту же сетку.
