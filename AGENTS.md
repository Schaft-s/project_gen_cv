# Инструкция агенту

Ты реализуешь **один** этап итогового проекта по диффузионным сэмплерам. Не делай весь проект сразу.

## Перед кодом

1. Прочитай `docs/plan.md`.
2. Прочитай `docs/methods.md`.
3. Прочитай бриф своего этапа: `docs/stages/sN_*.md`.
4. Если этап про опыты — ещё `docs/experiments.md`.
5. Не читай `docs/archive/` как ТЗ: это черновик другой модели.

## Правила

- Только файлы своего этапа и тесты к ним. Соседний код не «улучшать».
- Формулы брать из `docs/methods.md`, не из памяти Diffusers «примерно».
- MATCH и RESEARCH не смешивать, см. план.
- Новые зависимости не добавлять без записи в `requirements.txt`. Держать `transformers<5` и `huggingface-hub<1`: иначе ломается Diffusers 0.32.
- На MPS генератор для Diffusers — CPU (`torch.Generator(device="cpu")`).
- Секреты и гигантские `.pt`/PNG не коммитить.
- Если сверка с Diffusers не проходит — остановиться и зафиксировать ошибку, не переходить к FID/поиску.

## Проверка

Критерий готовности — секция **«Готово когда»** в брифе этапа. Прогони указанные команды локально (MPS/CPU). Colab — только если бриф это пишет.

## Где что лежит

```
src/gencv/            пакет
src/gencv/samplers/   DDIM, Heun, DPM-Solver++
scripts/              входные точки этапов
tests/                численные проверки
configs/default.yaml  замороженные гиперпараметры
outputs/              артефакты прогонов, gitignored
data/                 банки шумов и опоры, gitignored
```
